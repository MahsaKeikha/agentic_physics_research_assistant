# Specialized agents
- Research Lead: decomposes the physics question and coordinates the workflow.
- Theory Analyst: develops assumptions, models, and derivations.
- Computational Checker: checks calculations and numerical consistency.
- Evidence Reviewer: tracks sources, uncertainty, and unsupported claims.
- Safety Reviewer: identifies dual-use, experimental, and overclaiming risks.
- Synthesis Reviewer: prepares the human-reviewable research brief.
