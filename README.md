# Agentic Physics Research Assistant

F81 in the Agentic AI Library. A safety-aware multi-agent reference system for physics research planning, derivation review, evidence tracking, computational checks, and human-reviewed scientific synthesis.

## Architecture
Specialized agents collaborate through explicit state, orchestration, evidence discipline, evaluation, observability, and human approval. The system is decision support and does not present unverified outputs as established scientific results.

## Repository structure
`AGENTS/`, `SKILLS/`, `TOOLS/`, `orchestration/`, `memory/`, `observability/`, `evals/`, `benchmarks/`, `examples/`, `config/`, `prompts/`, `docs/`, and `tests/` contain the reference implementation assets.

## Run
```bash
python run.py
python -m pytest -q
```
